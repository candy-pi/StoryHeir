# 模块 D · 家风提取(Family Values)设计

> 对应总纲方向 6。**独立、轻量、情感共鸣强**,适合作热身或穿插。不依赖 A/B/C。

## 一、目标

从所有家族故事里自动提取"家风/价值观"——老人话里那些"做人要诚信""吃亏是福""勤俭持家"——在首页/编年志展示成「我们家的家风」。

> 这是很多家庭真正想留下的东西,比故事本身更"可传承"。改动小、见效快、Demo 视觉好。

## 二、与现有架构的接缝

| 现状 | 改造 |
|------|------|
| genStory 只生成故事正文 | (可选)生成时顺带抽 values;或独立云函数 `extractValues` |
| 首页只有故事列表 | 加「我们家的家风」标签墙区 |
| 无 values 数据 | 存 memory(kind=value) 或独立 `familyValue` 集合 |

> 若模块 A 已落地,values 作为 `memory.kind=value` 统一存;若 A 未做,用独立集合(本模块自洽)。

## 三、数据模型

```js
// familyValue 集合(或 memory.kind=value)
{
  _id,
  familyId: "default",
  value: "诚信",           // 家风关键词(2-4 字)
  quote: "做人要诚信",      // 原句出处
  sourceStoryId: "story_xxx",
  count: 3,                // 该价值观在多少篇故事里出现(权重)
  createdAt
}
```

## 四、提取流程

```
输入:某 family 全部 story.content
GLM 抽取:
  prompt: "以下是这个家庭的往事。请提炼出体现的家风/价值观,
          每条给:关键词(2-4字)、原句出处、出自哪篇。
          只抽明确体现价值观的,不要硬凑。输出 JSON 数组。"
输出: [{ value:"诚信", quote:"做人要诚信", sourceStoryId }, ...]
归并:按 value 关键词合并,count++,收集所有 sourceStoryId/quote。
```

触发时机(三选一/组合):
- genStory 后增量提取(只处理新故事);
- 手动"刷新家风"按钮(全量重算,简单可靠,推荐 MVP 用这个);
- 进入首页时若 values 为空则触发一次。

## 五、展示设计

**首页**(在 hero 下方、故事列表上方):
```
┌─────────────────────────────┐
│  我们家的家风                 │
│  [诚信] [勤俭] [吃亏是福]      │
│         [尊老] [善良]         │
└─────────────────────────────┘
```
- 标签墙,count 越大字号越大/越靠前(词云感,但用纯 flex 即可)。
- 点标签 → 展开原句 + 出处故事链接。

**编年志**(卷首封面下):加一行"家风:诚信 · 勤俭 · ..."。

## 六、改动点清单

- **新增集合**:`familyValue`(若 A 未做)或复用 memory
- **云函数**:新增 `extractValues`(遍历 story → GLM 抽取 → 归并写回)
- **genStory**(可选):生成后顺带抽当前故事的 values
- **index.js/wxml/wxss**:家风区(拉取 + 标签墙 + 点击展开)
- **chronicle.wxml**:封面下加家风行

## 七、实施任务清单(批准后转 plan)

- [ ] familyValue 集合 + 权限
- [ ] extractValues 云函数:抽取 prompt + JSON 解析 + 归并
- [ ] index.js:加 loadValues + 点击展开逻辑
- [ ] index.wxml/wxss:家风标签墙(字号随 count)
- [ ] chronicle:封面家风行
- [ ] 触发入口:首页"刷新家风"按钮 或 genStory 后自动
- [ ] 真机验证:录入含明显价值观的故事后,家风墙正确出现

## 八、风险与对策

| 风险 | 对策 |
|------|------|
| 价值观抽取主观、可能硬凑 | prompt 限制"只抽明确体现的";带原句出处可人工校验 |
| 重复/近义(诚信/诚实) | 归并时做简单近义合并表;MVP 接受少量重复 |
| 老故事多时全量重算慢 | 增量提取(只处理新 story);或后台触发+loading |

## 九、验收标准

1. 录入含"做人要诚信""吃亏是福"的故事后,家风墙出现「诚信」「吃亏是福」标签。
2. 同一价值观在多篇出现时,count 累加,标签更显眼。
3. 点标签能看到原句和出处故事。

## 十、比赛加分点

- **情感共鸣**:家风是家族传承的核心,"AI 帮家里提炼家风"直击产品价值。
- 视觉好呈现:首页一个家风墙,评审一眼能懂。
- 独立可做:不依赖其他模块,可作第一个落地项快速见效,降低整体推进风险。
