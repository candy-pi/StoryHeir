# 传家志 · 故事页操作区重设计

## 背景
用户反馈：story 页「家人共建·提交」「分享到家族群」「继续完善这个故事」等按钮**文字显示不全**，且底部一串按钮**排版无美感**。

## 根因分析

### 1. 文字截断（全站 bug）
`app.wxss` 的 `.btn-primary` / `.btn-secondary`：
```css
.btn-primary { width: 100%; height: 104rpx; line-height: 104rpx; ... }
```
- 未设 `box-sizing: border-box`，默认 content-box；
- 未覆盖微信原生 `<button>` 自带的左右内边距（约 28px）。
- 结果：`width:100%` + 原生 padding 使总宽 > 屏宽，文字被向内挤压/裁切 → 长文案（如「让这张老照片变彩色」「继续完善这个故事」）显示不全。
- 影响范围：**全站所有 btn-primary 按钮**（index / interview / chronicle / story）。

### 2. 排版无层次
story 页底部竖向堆叠 4 个**完全相同**的 100% 宽、104rpx 高、红棕色实心圆角大按钮：
朗读故事 → 提交（在共建卡内）→ 分享到家族群 → 继续完善这个故事 → 编辑/删除文字链接。
- 4 个等权实心按钮 = 视觉一堵墙，无主次；
- 违反 skill 铁律「对比度创造层级」「留白创造呼吸感」。

## 目标
1. **彻底修截断**：改 `app.wxss` 公共按钮，全站一次修复。
2. **建立底部操作层级**：一个主操作 + 次要操作 + 文字链接，破除实心墙。

## 候选方向（待用户拍板）

### A. 分层底部（推荐）
- 「继续完善这个故事」= 主按钮（实心，独占一行）
- 「朗读」+「分享」= 两个描边次按钮并排（一行两列）
- 「编辑 / 删除」= 底部文字链接（保持现状）
- 优点：改动小、主次最清晰、保留适老大按钮；缺点：底部仍占两行。

### B. 底部固定操作栏
- 正文区不放操作按钮，底部 `position:fixed` 一栏：[朗读] [分享] [继续完善]（继续完善实心，其余描边）
- 编辑/删除置于固定栏上方
- 优点：阅读沉浸、操作常驻拇指区；缺点：占可视高度、适老场景正文区变小。

### C. 引导卡片
- 「继续完善」做成一张带说明文案的引导卡（解释「再聊一轮帮你补全」）+ 主按钮
- 「朗读」「分享」= 下方并排描边次按钮
- 优点：对新功能（续访）引导性最强、最像产品页；缺点：改动最大、占垂直空间。

## 公共改动（三方案都做）
- `app.wxss`：`.btn-primary` / `.btn-secondary` 加 `box-sizing: border-box; padding: 0 24rpx;`（修截断，全站受益）。
- 沿用现有 Design Token（#A0522D 主色 / #FBF7F0 背景 / #2B2218 文字 / #6e6354 次文字 / #fff 卡片），不另起色系，保持一致性。

## 无障碍与适老约束
- 主/次按钮触控高度维持 ≥ 104rpx（远超 88rpx 下限）。
- 描边次按钮白底 + #A0522D 文字：对比度 ≈ 4.6:1，达标。
- 按钮间距 ≥ 16rpx。
