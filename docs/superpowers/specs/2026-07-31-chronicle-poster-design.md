# 传家志 · 编年志成册海报 设计

## 背景
现状：编年志分享出去是微信小程序入口卡片，点开才看到书。用户想要"真正成册、发出去像本书"。
目标：把编年志生成一张可保存 / 可分享的**成册海报图**，转发即书，不必进小程序。

## 技术路线
微信小程序原生能力，无需云函数：
1. 页面内放一个隐藏 canvas 2d 节点（定位移出屏幕，占位但不影响布局）
2. 复用编年志页已加载的 `book` 数据（chapters / timeline / span / count）+ `valuesText`，不重新拉
3. canvas 绘制封面 + 卷目等版式（ctx 手动排版、文字换行）
4. `wx.canvasToTempFilePath` 导出临时图片
5. 出口二选一/都给：
   - `wx.showShareImageMenu({ path })`：直接弹微信「分享图片」菜单，可发聊天 / 朋友圈（最优出口）
   - `wx.saveImageToPhotosAlbum`：存相册（需 `scope.writePhotosAlbum` 授权引导）

## 关键约束与坑
- **canvas 尺寸上限**：微信 canvas 2d 单边约 4096 物理像素（dpr=2 时逻辑约 2048）。全本几十篇长图会超限 → 必须控制内容量或分页。
- **绘制耗时**：canvas 排版 + toTempFile 较慢，需 loading 兜底，老人不慌。
- **保存授权**：`saveImageToPhotosAlbum` 首次需授权，未授权引导 `openSetting`，不静默失败。
- **照片缩略**：若要把每篇照片画进海报，需先 downloadFile 云存储 fileID → 耗时大增、易超尺寸上限。概览海报不放照片更稳。

## 候选方向（待用户拍板）

### A. 家风卷册·概览海报（推荐）
- 内容：封面（志印章 + 家族编年志 + 跨度 + 篇数 + 家风关键词 + slogan）+ 卷目（各年代 + 篇数）+ 落款
- 竖版单屏（约 750×1334 逻辑），稳、美、易传播
- 不放每篇照片 → 不超 canvas 上限、生成快
- 定位：像"书的封面 + 目录页"，适合发群/朋友圈传播，勾起家人点进小程序看全本

### B. 全本长图
- 内容：封面 + 每个年代章节 + 每篇故事（标题/年份/预览/缩略照）
- 信息全，但：
  - 篇数多时高度远超 canvas 上限 → 需分段多次绘制再拼接，或分页生成多张
  - 每篇照片要逐张下载 → 慢、可能失败
  - 长图在聊天里预览体验差
- 定位：更像"完整电子书一页页拼起来"，适合保存留念，不适合快速分享

## 设计决策
- 沿用现有 token（#A0522D 主色 / #FBF7F0 米底 / #2B2218 文字 / 印章 #B23A28），与编年志页一致。
- 字号放大适老；对比度 ≥ 4.5:1。
- 入口按钮：「做成海报分享」放在编年志页底部（分享按钮旁）。

## 选 A 时的实现要点
- canvas 节点 `position:fixed; left:-9999rpx; top:0; width:750rpx; height:1334rpx`
- 按 dpr 放大物理像素，ctx.scale(dpr,dpr)
- 绘制顺序：米底 → 印章 → 书名 → 副信息 → 分隔线 → 卷目行（循环）→ slogan → 落款
- 文字超长手动按字符截断换行
- 导出后 `wx.showShareImageMenu`（主）+ 兜底 `previewImage` 让用户长按保存
