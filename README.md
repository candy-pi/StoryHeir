# 家忆录（StoryHeir）

家忆录是一款微信小程序。AI 记者「小传」通过老照片和话题引导家人讲述往事，将文字或语音访谈整理成故事，再按年代汇编成家族编年志。

参赛项目 · 2026 微信小程序开发大赛「与 AI 共生」

## 使用流程

1. 在首页创建家族，或输入家人发来的家族 ID 加入。创建者可在首页删除自己创建的家族。
2. 点击「开始一段家族访谈」，选择所属家族。可从老照片或话题开始，以文字或语音回答，访谈过程中也可以补照片。
3. 生成故事草稿后，点击顶部「发布」，填写或选择讲述人并填写采访人署名。正式发布后，故事进入所选家族的故事库。
4. 家族成员可以阅读、朗读故事，查看 AI 提问和受访者回答的文字原文，也可以把故事卡片转发给微信好友或群聊。打开卡片仍需通过家族成员校验。
5. 在家族详情中可刷新「我们的家风」，从已发布的故事提炼人物精神，点击标签查看引文和出处。编年志按事件年代分章，提供时间线和分享海报。

## 页面与目录

| 路径 | 用途 |
| --- | --- |
| `miniprogram/pages/index` | 我的家族、创建／加入／删除家族、访谈入口 |
| `miniprogram/pages/interview` | 照片和话题引导、普通话／粤语语音或文字访谈、续访和生成故事 |
| `miniprogram/pages/story` | 故事草稿和个人故事详情、多图、照片上色、关系图、朗读、补充记录、编辑与发布入口 |
| `miniprogram/pages/family` | 家族详情、发布表单、已发布故事、采访原文和家风 |
| `miniprogram/pages/chronicle` | 当前家族的编年志、时间线和海报 |

`cloudfunctions/` 存放云端代码，`tests/` 存放模型提示词对比脚本，`docs/superpowers/` 保留历史设计和开发计划。

## 云端服务

| 云函数 | 职责 |
| --- | --- |
| `family` | 家族成员管理、故事发布与读取、采访原文、编年志 |
| `chat` | 看照片开场、追问、提问质量校验 |
| `chatStream` | 提供 `POST /chat`，以流式响应返回访谈追问 |
| `asr` | 语音转写 |
| `genStory` | 生成或更新草稿，保存访谈问答并抽取年代、人物和关系 |
| `restore` | 老照片上色 |
| `tts` | 访谈问题与故事朗读 |
| `extractValues` | 按家族提炼家风，统计多个故事共同体现的精神品质 |

除 `family` 外，其余七个云函数使用阿里云百炼。

## 本地配置与部署

1. 用微信开发者工具导入项目。在 `project.config.json` 中配置自己的 AppID，在 `miniprogram/config.js` 中配置云开发环境 ID。
2. 创建下表所列的数据库集合并设置权限。使用原有环境时，先检查既有规则是否仍允许跨家族读取。
3. 部署 `cloudfunctions/` 内的八个函数并安装依赖。`chatStream` 需要部署为支持 HTTP 流式响应的云函数，使小程序能通过 `wx.cloud.callHTTPFunction` 调用 `POST /chat`。
4. 给使用百炼的七个函数配置云端环境变量 `DASHSCOPE_API_KEY`。可按各函数代码设置 `DASHSCOPE_MODEL` 等可选变量。凭证仅保存在云端环境变量中。
5. 真机预览，验证创建和加入家族、语音转写、生成与发布故事、原文查看、家风刷新、编年志和微信分享。用另一个未加入该家族的账号验证分享卡片及相关数据访问会被拒绝。

### 数据集合与权限

| 集合 | 用途 | 客户端权限建议 |
| --- | --- | --- |
| `families` | 家族、创建者和成员列表 | 禁止直接读写，经云函数访问 |
| `familyStories` | 已发布故事及采访原文快照 | 禁止直接读写，经云函数访问 |
| `familyNarrators` | 家族讲述人 | 禁止直接读写，经云函数访问 |
| `familyValue` | 按家族保存的家风标签、引文和来源 | 禁止直接读写，经云函数访问 |
| `story` | 作者的故事草稿和个人故事源记录 | 仅允许作者访问自己的记录 |
| `interview` | 原始访谈问答 | 仅允许作者访问自己的记录 |
| `contribution` | 个人故事页的补充、校对和认人留言 | 发布前限制读取范围和写入权限，避免公开读写 |

家族云函数使用微信云开发提供的 `OPENID` 校验身份。集合权限和云存储权限仍需在部署环境中核对。家族故事列表及家风提炼有按 `familyId` 筛选并按 `publishedAt` 降序的查询，遇到索引错误时可检查 `familyStories` 的组合索引。

### 隐私与历史数据

- 录音、照片、访谈文字和故事内容会在相应功能中交给百炼处理。发布前应核对隐私指引与媒体文件的实际访问权限。
- 旧故事只有在原访谈记录仍存在且关联可追溯时，才会显示采访原文。旧的个人家风记录不会自动归入家族。
- 当前代码仍有待核查的隐私边界，包括访谈和媒体文件的归属校验，以及编年志接口和日志中的数据范围。上线前应结合实际云端规则验证这些路径。
 - 新上传的访谈照片和录音使用 `private-media/<OPENID>/` 路径。云存储规则须把该目录的客户端读写限制为文件创建者，并禁止覆盖其他用户的文件。编年志通过成员校验后会为符合归属要求的新照片签发临时链接。
 - 旧照片、旧上色图和旧朗读缓存使用历史路径，发布前应核对现有存储规则与兼容性。勿直接覆盖整个存储桶规则，否则历史照片和缓存音频可能无法播放。旧版故事中已经保存的采访快照应单独核查。
